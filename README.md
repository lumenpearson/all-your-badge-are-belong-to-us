# All your badge are belong to us

```
In A.D. 2026, war was beginning.
Captain:  What happen?
Mechanic: Somebody set up us the achievements.
Operator: We get signal.
Captain:  What!
Operator: Main profile turn on.
CATS:     How are you gentlemen!!
CATS:     All your badge are belong to us.
CATS:     You have no chance to survive make your time.
```

Это репозиторий для накрутки ачивок GitHub. Да, честно и с иронией.

*For great justice.*

## Происхождение мема

«All your base are belong to us» — фраза из заставки европейской версии игры
[Zero Wing](https://en.wikipedia.org/wiki/All_your_base_are_belong_to_us) (Sega Mega Drive, 1991),
переведённой с японского так, что в начале 2000-х она стала одним из первых интернет-мемов.
